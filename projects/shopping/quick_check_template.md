# Quick Check Template

## Purpose
Define the output structure for `quick_check.md`. This file owns presentation only.

Keep the result compact unless the evidence requires more explanation.

## Required order
### Answer
Directly answer the user's narrow question: suitability, compatibility, red flags, deal sanity, or whether the product is worth considering.

### Key reasons
Give the 2-4 decision-relevant reasons supporting the answer.

### Main caveat / uncertainty
State the most important limitation, unknown, or tradeoff when one exists.

### Price / seller note
Include only when the user supplied or asked about a concrete offer, current price, retailer, returns, warranty, or deal quality.

### Broader-market note
Include only when a full Product Research workflow is actually warranted. State why broader comparison could change the decision.

### Sources
Provide concise citations/sources for externally verified claims. Do not expose internal compliance machinery unless requested or audited.

## Formatting
- Lead with the answer rather than a long research preamble.
- Do not create a large comparison table unless the Quick Check has legitimately escalated beyond its intended scope.
- Do not force a binary buy/do-not-buy label when missing preference information creates a real decision boundary.
