# Product Research Workflow

## Purpose
Own full-market product research, comparison, and recommendation behavior.

## Inputs
Use the product context already resolved by `instructions.md`: Base plus any active Class, Category, Type, shared-authority sections, and specialized files.

## Initial workflow stub
1. Capture material user constraints and intended use.
2. Discover a broad candidate set using the active `source_playbooks.md` guidance.
3. Narrow to credible candidates before deep evidence collection.
4. Lock exact model/variant when conclusions depend on it.
5. Evaluate candidates using active `criteria.md`, `pricing.md`, and specialized hierarchy guidance.
6. Apply `research_sources.md`; use `reviews.md` and `seller_instructions.md` when relevant.
7. Synthesize the recommendation using `product_research_template.md`.

## Next expansion
Migrate candidate-pool, research-depth, variant-lock, claim-map, and synthesis rules from the legacy full-research workflow.

## Boundary
This workflow does not own product classification or redefine shared authorities.
