# Research Source Authority

## Purpose

This file owns evidence admissibility, weighting, recency, breadth, conflict handling, and claim-to-evidence discipline for Shopping research.

The previous implementation is preserved at `archive/research_sources.md`. Its detailed rules will be migrated deliberately; archived rules are not active implicitly.

---

## Initial live contract

- Separate discovery-only sources from evidence used to support conclusions.
- Match evidence type to claim type.
- Prefer primary/standards sources for objective specifications and compliance facts when available.
- Prefer transparent method-based evidence for empirical performance claims.
- Use broad real-world owner/community signal for reliability and long-term-use claims.
- Treat current prices, availability, policies, firmware/software behavior, and current product revisions as recency-sensitive.
- State material conflicts, uncertainty, and coverage gaps rather than hiding them.
- When review evidence is active, defer review-content interpretation to `reviews.md`.
- When seller/listing evidence is active, defer seller/channel legitimacy and purchase-risk interpretation to `seller_instructions.md`.

---

## Boundary

This file decides whether and how sources may support claims. It does not decide when this authority is activated, own source-discovery playbooks (`source_playbooks.md`), review-content interpretation (`reviews.md`), seller/channel risk (`seller_instructions.md`), product classification (`product_types.md`), or pricing strategy (`pricing.md`).
